API / Data Access

Access Beacon data programmatically. All endpoints are static JSON files.

Endpoints

EndpointDescription
/data/resources.jsonFull dataset with all fields
/data/index.jsonCompact index (id, name, county, needs, phones)
/data/resources-by-county/{county}.jsonResources for a specific county
/data/resources-by-need/{need}.jsonResources for a specific need
/data/resources.csvCSV export of all resources

Example: Fetch resources for Knox County

const response = await fetch('https://mrstewood.github.io/beacon/data/resources-by-county/knox.json');
const data = await response.json();
console.log(`${data.count} resources in Knox County`);
data.resources.forEach(r => console.log(r.name));

Example: Search for food resources

const response = await fetch('https://mrstewood.github.io/beacon/data/resources.json');
const data = await response.json();
const food = data.resources.filter(r => r.needs.includes('food'));
console.log(`${food.length} food resources statewide`);
