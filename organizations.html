API / Data Access

Access Beacon data programmatically. All endpoints are static JSON files.

EndpointDescription
/data/resources.jsonFull dataset with all fields
/data/catalog.jsonNational index (state listing)
/data/states/ky/index.jsonKentucky state index
/data/states/ky/resources.jsonKentucky full data
/data/v3/resources.jsonV3 schema with locations

Example: Fetch Kentucky resources

const response = await fetch('https://mrstewood.github.io/beacon/data/states/ky/index.json');
const data = await response.json();
console.log(`${data.total_resources} resources in Kentucky`);
